# Catalogue LYSCO HQ

Branche gérée par la **Market place** du QG : agents, skills et MCP **publics** uniquement.
Un élément marqué privé dans le QG ne vient jamais ici. Ne pas modifier à la main : passer par la Market place.

- `agents/<id>.md` : fiche de l'agent, `agents/<id>.json` : sa place dans l'équipe (nom, pôle, rôle).
- `skills/<id>/` : le skill (`SKILL.md` et ses fichiers).
- `mcp/<id>.json` : la connexion MCP, sans jeton ni valeur d'environnement.
